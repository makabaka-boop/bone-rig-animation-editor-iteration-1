# 二维骨骼动画编辑器

React + Canvas + TypeScript 实现的 2～15 根骨骼二维动画编辑器。

## 功能

- **骨骼树**：骨骼构成单根父子树（2～15 根），支持新增、删除（级联删子树 / 保留子级上移）、
  在检查器下拉框中修改父子关系；挂到自身或自己后代会被拒绝（防环）。
- **关键帧**：每根骨骼一条轨道，关键帧保存**局部角度与长度**；播放时先沿时间插值
  （角度走最短弧，长度线性），再由根到叶求全局姿态。
- **逆向定位（IK）**：拖动任意骨骼末端控制点，对其父→子两节骨链做解析 IK：
  - 目标超出 `l1+l2`（或近于 `|l1-l2|`）时末端贴到可达包络边界，画布显示贴边提示；
  - 遵守各关节最小/最大角度限制，限位下给出末端误差最小的盒内最优解；
  - 拖动整个过程只产生**一条**撤销记录，ESC 可取消本次拖动。
- **统一可撤销历史**：结构编辑（增删、改父子、改约束）与姿态编辑（拖动产生关键帧）
  进入同一条历史，Ctrl+Z / Ctrl+Y 撤销重做，撤销后可立即重播。
- **统一修订快照**：播放画面、检查器单帧数值检查、JSON 导出都取自同一个冻结的
  `RevisionSnapshot`（带单调递增 `rev`），三处数据必然一致。
- **迟到结果保护**：拖动中的 IK 经 `RevisionGate` 带修订号调度，计算期间若发生
  撤销/结构编辑等新修订，迟到的结果直接丢弃，不覆盖新修订。

## 操作

| 操作 | 方式 |
| --- | --- |
| 逆向定位 | 指针拖动画布上的蓝色末端控制点 |
| 选择骨骼 | 点击骨骼段/控制点，或左侧树 |
| 插入关键帧 | 选中骨骼后在检查器点「在当前时刻插入帧」（拖动会自动在当前时刻写帧） |
| 播放/跳转 | 底部时间轴：播放按钮、点击轨道、点击黄色帧圆点 |
| 改父子关系 | 检查器「父骨骼」下拉（环与自引用被禁止） |
| 改约束 | 检查器关节最小/最大角（度），已有姿态与关键帧会被夹回新区间 |
| 撤销/重做 | Ctrl+Z / Ctrl+Y（拖动中禁用）；ESC 取消拖动 |
| 导出 | 工具栏「导出快照 JSON」（含文档、24fps 逐帧世界姿态、校验结果、rev） |

## 架构

```
src/core/                 纯逻辑，无 React 依赖（可直接单测）
  types.ts                Bone / Keyframe / SkeletonDocument / WorldPose
  math2d.ts               向量、角度归一化、最短弧插值
  skeleton.ts             树校验(canReparent)、级联删除、轨道采样、前向运动学 evaluatePose
  ik.ts                   两节骨链解析 IK：不可达贴边 + 关节限位盒内最优
  history.ts              统一历史栈（commit/undo/redo + 单调 rev）
  revision.ts             RevisionGate：修订闸门，丢弃迟到的异步计算结果
  validation.ts           环/悬挂引用/越界帧/限位/骨骼数等完整性检查
  snapshot.ts             RevisionSnapshot（深冻结）+ exportSnapshot 逐帧导出
  store.ts                EditorStore：结构与姿态编辑的唯一入口、拖动会话
src/ui/                   Canvas / 树 / 检查器 / 时间轴 / 工具栏
tests/                    vitest：40 个用例
```

### 关键设计

- **局部量存储，世界量播放时求**：`Bone.angle` 与关键帧角度都是相对父骨骼的局部角；
  `evaluatePose` 从根按拓扑序累加世界角。删骨保留子级时，子骨局部角补上被删骨的
  局部角以保持世界方向。
- **IK 角度约定**：局部角是「方向角」。解析解的子局部角为 ±a2（余弦定理）；
  限位下除两组解析分支外，还加入「子角固定在边界反解父角」「父角固定在边界反解子角」
  的候选，所有候选统一夹到限位盒后按末端误差打分。
- **拖动的修订语义**：每次 `updateDrag` 推进 `rev`（使在途 IK 失效）但不进历史；
  `endDrag` 把整个拖动压缩为一条历史记录。
- **删除即清理**：级联删除连同轨道一并删除，校验器保证不存在引用已删除骨骼的帧。

## 开发

```bash
npm install
npm run dev      # 开发服务器
npm test         # vitest 单次运行（40 tests）
npm run build    # tsc 类型检查 + vite 构建
```

## 测试覆盖

- `coordinates.test.ts`：局部→世界坐标变换、多级旋转累加、拓扑序、最短弧角度插值
- `ik.test.ts`：可达目标精确命中、不可达目标贴外包络/内包络、斜向贴边方向、
  单关节/双关节限位边界、祖父世界方向基准
- `store.test.ts`：防环拒绝、级联删除不留悬挂帧、15 骨上限、拖动贴边界、
  限位不越界、一次拖动一条历史、撤销后重播一致、结构/姿态历史交错撤销
- `revision.test.ts`：修订前进丢弃迟到结果、`sync` 对齐、模拟连续拖动旧结果不覆盖
- `snapshot.test.ts`：播放/数值/导出共用同一 rev、快照冻结、导出逐帧采样
